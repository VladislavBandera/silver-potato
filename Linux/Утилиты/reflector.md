reflector: утилита для сортировки и отбора серверов загрузки пакетов для файловых менеджеров pacman и paru (или другие на основе aur).

Файл конфигурации лежит по пути: /etc/xdg/reflector/reflector.conf

с помощью сервиса timer: Можно включить обновление списка серверов каждую неделю по умолчанию или выставить свои параметри в конфигурационом файле данного сервиса.  

Конфигурационный файл:

--save путь_сохранения_файла
--protocol протокол_передачи
--latest количество_серверов_в_списке_после_перебора
--country перечень_допустимых_стран_для_добавки (France, Germany, ...)

--sort тип_сортировки_серверов (
country - название странны,
score - по оценке MirrorStatus, 
delay - задержка MirrorStatus, 
age - последняя синхронизация сервера,
rate - выбирает самые быстрые сервера
)
