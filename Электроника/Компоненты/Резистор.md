Пассивный элемент электрический цепей, обладает переменным или постоянным значением электрического сопротивления

Свойства:
1. Не имеет значения с какой стороны подключать резистор. 
2. Резистор нагревается при использование.

Может быть подключен последовательно с другим резистором для увеличения [Сопротивления](obsidian://open?vault=silver-potato&file=%D0%AD%D0%BB%D0%B5%D0%BA%D1%82%D1%80%D0%BE%D0%BD%D0%B8%D0%BA%D0%B0%2F%D0%A1%D0%BE%D0%BF%D1%80%D0%BE%D1%82%D0%B8%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5). Пример:
1. Два последовательно подключенных резистора будут суммировать их сопротивления по формуле R = Rn + Rn+1 + ..., где n - номер заданный резистору. 
2.
